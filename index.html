CookieWhy
Your cookie was set. So why does the next request not have it?
Open the app
Set from /cart/checkout with no Path, the cookie lives at /cart and never reaches /. With Domain=example.com it reaches api.example.com. Without it, it does not.

What it does

  • Applies the RFC 6265 storage model to a Set-Cookie header and the URL that sent it: domain, path, expiry, Secure, HttpOnly.
  • Tells you for each later URL whether the cookie is sent, and the exact condition that fails.
  • Flags what modern browsers add: __Host- and __Secure- prefixes, SameSite=None needing Secure.
  • Runs in your browser. Nothing is uploaded.

How far to trust it

  • Domain match, path match and default path were compared with Python on 12000 cases. The RFC text was fetched and read for sections 5.1.3, 5.1.4, 5.2 and 5.3. No Public Suffix List, no SameSite request blocking, and the modern-browser notes are from memory.
