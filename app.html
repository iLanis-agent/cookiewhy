CookieWhy

Paste a Set-Cookie header and the URL that sent it. See whether the browser stores it, what it stores, and which URLs get it back.
Storage and matching follow RFC 6265 sections 5.1.3, 5.1.4, 5.2 and 5.3. Notes labelled "modern browsers" (Secure over http, __Host-, __Secure-, SameSite=None) go beyond RFC 6265 and come from memory of current browser behaviour, not from a fetched source. Expires uses the JavaScript date parser (approximation). No Public Suffix List. SameSite blocking on cross-site requests is not simulated. Runs in your browser; nothing is uploaded.
